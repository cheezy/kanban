# Stride Configuration

The after_doing and after_goal layout, and why it fits the hook time budget,
is explained in docs/hook-time-budget.md. Make every hook change in both
.stride.md and .stride_dev.md: ./stride_dev.sh copies .stride_dev.md over
.stride.md.

## before_doing

```bash
git diff --quiet && git diff --cached --quiet || { echo "Working tree is dirty — commit or stash before claiming a task"; exit 1; }
git checkout main
git pull --rebase origin main || { git rebase --abort 2>/dev/null; echo "pull --rebase conflicted with local unpushed commits — resolve manually"; exit 1; }
mix deps.get
mix hex.outdated || { echo "Outdated dependencies — upgrade before claiming"; exit 1; }
mix deps.audit || { echo "Vulnerable dependencies — patch before claiming"; exit 1; }
mix hex.audit || { echo "Retired dependencies — replace before claiming"; exit 1; }
mix ecto.migrate
git checkout -B "$TASK_IDENTIFIER"
```

## after_doing

```bash
bash test/partitioned_test.sh --warnings-as-errors
MIX_ENV=test mix format --check-formatted
MIX_ENV=test mix credo --strict
MIX_ENV=test mix sobelow --config
[ -z "$(git status --porcelain --untracked-files=all)" ] || (git add -A && git commit -m "Completed task $TASK_IDENTIFIER: $TASK_TITLE")
m="$(git rev-parse --git-path stride-green-tree)"; if [ -z "$(git status --porcelain --untracked-files=all)" ]; then git rev-parse 'HEAD^{tree}' > "$m"; else rm -f "$m"; fi
```

## before_review

```bash
git checkout main
git merge --ff-only "$TASK_IDENTIFIER" || { echo "main moved since branching — ff-only merge of $TASK_IDENTIFIER failed; resolve manually"; exit 1; }
git branch -d "$TASK_IDENTIFIER"
```

## after_goal

```bash
git checkout main
git fetch origin main
git rebase origin/main || { git rebase --abort 2>/dev/null; echo "rebase onto origin/main conflicted — resolve manually, then re-run after_goal"; exit 1; }
MIX_ENV=test mix do compile --warnings-as-errors + deps.unlock --unused + format + gettext.extract --check-up-to-date + dark_mode.scan + dark_mode.contrast --enforce + credo --strict
m="$(git rev-parse --git-path stride-green-tree)"; t="$(git rev-parse 'HEAD^{tree}')"; if [ -n "$(git status --porcelain --untracked-files=all)" ]; then echo "the working tree differs from HEAD, so the suite would not test what is pushed; commit or remove these changes, then re-run after_goal; not pushing"; git status --short --untracked-files=all; exit 1; elif [ -f "$m" ] && [ "$(cat "$m")" = "$t" ]; then echo "test --warnings-as-errors already passed on tree $t in after_doing; not re-run"; else bash test/partitioned_test.sh --warnings-as-errors || { echo "test --warnings-as-errors failed on the tree being pushed; not pushing"; exit 1; }; fi
git push origin main
```
