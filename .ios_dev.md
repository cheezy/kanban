# Stride Configuration

The iOS hook set. ./ios_dev.sh copies this file over .stride.md, and
./stride_dev.sh copies the Phoenix set back. docs/hook-time-budget.md explains
both. .stride.md is tracked, so in this mode it differs from the committed copy.
The lines below leave it out of their clean-tree checks and commits.

## before_doing

```bash
git diff --quiet -- . ':(exclude).stride.md' && git diff --cached --quiet -- . ':(exclude).stride.md' || { echo "Working tree is dirty — commit or stash before claiming a task"; exit 1; }
git checkout main
git pull --rebase --autostash origin main || { git rebase --abort 2>/dev/null; echo "pull --rebase conflicted with local unpushed commits — resolve manually"; exit 1; }
git reset --quiet -- .stride.md && ./ios_dev.sh
mix deps.get
mix hex.outdated || { echo "Outdated dependencies — upgrade before claiming"; exit 1; }
mix deps.audit || { echo "Vulnerable dependencies — patch before claiming"; exit 1; }
mix hex.audit || { echo "Retired dependencies — replace before claiming"; exit 1; }
mix ecto.migrate
git checkout -B "$TASK_IDENTIFIER"
```

## after_doing

```bash
bash test/ios_test.sh
bash test/ios_elixir_checks.sh
[ -z "$(git status --porcelain --untracked-files=all -- . ':(exclude).stride.md')" ] || (git add -A -- . ':(exclude).stride.md' && git commit -m "Completed task $TASK_IDENTIFIER: $TASK_TITLE")
```
